# F&B SMART V5.1 — Documentation Reference

Đây là kho tài liệu tham khảo cho dự án F&B SMART V5.1.

## Thứ tự ưu tiên nguồn
1. KIM CHỈ NAM / Governance chính thức.
2. Quyết định PO đã được ghi nhận.
3. Tài liệu Product / Business / Technical đã được PO xác nhận.
4. Tài liệu tham khảo trong repository này.
5. Kiến thức bên ngoài.

Tài liệu trong kho này **không tự động trở thành quyết định sản phẩm**. Nội dung chưa được PO xác nhận phải được xem là tham khảo, TBD hoặc cần PO quyết định.

## Chuỗi hoàn chỉnh
Requirement → Feature → Screen → User Flow → Business Rule → Data → Repository → Work Item → Test → Build → PO Test → PO Verified → Protected → Locked

## Mục đích
Kho này giúp PO, ChatGPT và Coding Agent có một bộ tài liệu tham khảo thống nhất để tránh bỏ sót yêu cầu, giao diện, luồng người dùng, dữ liệu, quyền, kiểm thử và tiêu chí nghiệm thu.
